### 🚀 Featured Projects

#### 📊 DevPulse
A tool that generates instant analytics for any developer — just enter a GitHub username and get a breakdown of their activity, repositories, languages, and contribution patterns, with AI-generated insights on top.
- Pulls live data from the **GitHub API**
- Uses the **Gemini API** to generate readable, AI-powered summaries of a developer's profile
- Backend built with **Node.js**, **Express**, and **SQLite** for storage
- Frontend built with **React**

#### 🐘 Elephant Guard
A wildlife alert system that detects elephant movement near communities and sends real-time sighting alerts.
- **ESP32** + **LoRa** hardware nodes for long-range sighting detection between sender/receiver units
- **Firebase Realtime Database** for live data sync, with auto-reset logic for stale tower states
- Aggregates duplicate community sighting reports into a single alert
- Companion **React Native/Expo** app for viewing and reporting sightings
- Built collaboratively using Git workflows with a team

#### 🏛️ SmartGov
A civic services platform connecting citizens with local government institutions.
- **React Native** citizen-facing mobile app
- **React + TypeScript + Tailwind** admin web panel with role-based access (Super Admin / Institution Admin views)
- District-based admin routing and unified service types across institutions
- Real-time, institution-scoped alert notifications
- **Firebase** backend, including Firebase Auth with persistent sessions on mobile

#### 🚚 Smart Logistics & Delivery Operations Platform
A year-long university software engineering project (IN2901) — a dispatch and fleet management system built as part of a larger logistics platform.
- Leading a team of developers (Team Nexus) as part of this project
- Owns the **Dispatch & Fleet Management** module, coordinating a cross-module API contract with the shipment module
- Stack: **Spring Boot 3 / Java 21**, **React + TypeScript**, **React Native/Expo**, **PostgreSQL**, **Redis**, **RabbitMQ**
- Built with supervisor and industry-mentor guidance, including a formal SRS and MoSCoW-based MVP scoping
